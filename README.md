## 📌 About The Project

**Smart College Portal** is a web-based college portal developed for D. Y. Patil College of Engineering.

The application provides a single-page website experience using vanilla JavaScript, HTML, CSS and JSON without depending on any external framework.

## ✨ Features

- 📱 Responsive website layout
- 🧭 Dynamic navigation system
- 🔄 Single Page Application (SPA) architecture
- 📄 Dynamic page rendering
- 📂 JSON-based data management
- 📝 Contact and enquiry form validation
- 💾 LocalStorage-based enquiry saving
- ⚡ Lightweight frontend without frameworks

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Dynamic functionality |
| JSON | Data storage and management |
| LocalStorage | Saving enquiry data |

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone https://github.com/Vitthalgiri06/-WT_CCE5_12_SmartCollegePortal.git
```

**Step 2:** Open the project folder.

```bash
cd -WT_CCE5_12_SmartCollegePortal
```

**Step 3:** Start the local server.

```bash
python -m http.server 8000
```

**Step 4:** Open your browser and visit:

```text
http://localhost:8000/
```

You can also use the VS Code Live Server extension.

The objective of this project is to develop a lightweight, user-friendly college website using core frontend technologies while demonstrating SPA architecture, dynamic routing, JSON data handling and form validation.
